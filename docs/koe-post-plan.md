# こえポスト — 子ども専用・完全匿名の「こえ」投稿箱　設計書

作成: 2026-09-15 / 対象: `koe-post/`

## 0. ひとことで

**子どもが、家や学校で困っていること・してほしいことを、名前を出さずに書ける箱。**
書いた内容は子ども本人にも他の子どもにも見えない。見るのは、信頼できる大人（NPO・学校の先生）だけ。

## 1. 譲れない原則

| 原則 | 実装 |
|---|---|
| **完全匿名** | ログインなし。名前・メール・電話・端末IDを一切集めない。IPアドレスは保存しない（連投防止のため「その日限りの塩」でハッシュ化した値を1日だけ保持し、投稿には紐づけない） |
| **子どもは読めない** | 投稿の読み出しAPIは大人用クッキーが無いと 401。子ども側画面には一覧・検索・自分の投稿履歴が存在しない |
| **書いたら手元に残らない** | 送信後は内容を画面に再表示しない（親や友だちに画面を見られても分からない）。ブラウザにも保存しない |
| **危ないサインを見逃さない** | 本文をキーワード辞書で分類し、緊急度を3段階で自動付与。緊急は大人側の最上部に固定表示 |
| **子どもを一人にしない** | 送信後に必ず相談窓口（24時間対応）を表示。「いますぐ危ないときは 110 / 119」も明記 |
| **データ最小化** | 保存するのは：本文・カテゴリ・見てほしい相手・学年帯（任意）・学校コード（任意）・投稿日時・自動タグ・対応状況・大人のメモ。それだけ |

## 2. 検知（サイン分類）

本文をキーワード辞書に通し、該当したタグと緊急度を付けます（`src/lib/safety.ts`）。**あくまで「見落とし防止の目印」**で、最終判断は大人が行います。

| タグ | 緊急度 | 例（辞書の一部） |
|---|---|---|
| 自傷・希死念慮 | **緊急** | 死にたい／消えたい／いなくなりたい／リスカ／自殺 |
| 虐待・家庭内暴力 | **緊急** | 殴られる／叩かれる／蹴られる／ごはんをもらえない／家に帰りたくない／触られる |
| いじめ | 要注意 | いじめ／無視される／仲間はずれ／悪口／物を隠される／LINEで悪口／殴られる（学校） |
| 不登校・行きしぶり | 要注意 | 学校に行きたくない／学校が怖い／教室に入れない／休みたい／朝おなかが痛い |
| 孤立・不安 | 要注意 | ひとりぼっち／友だちがいない／話せる人がいない／不安／眠れない |
| 家庭の困りごと | 要注意 | お金がない／ごはんが少ない／親がケンカ／お世話をしている（ヤングケアラー） |
| 先生との関係 | 通常 | 先生が怖い／怒られる／えこひいき |
| 希望・提案 | 通常 | あったらいいな／ほしい／やりたい |

- 複数該当は全部タグ付け。緊急度は最も高いもの。
- 検知にひっかからなくても、子ども自身がカテゴリで「いじめ」「学校」を選べば同じタグを付与。
- 辞書は `safety.ts` の配列を編集するだけで増減できる。

### 傾向（ダッシュボード）
- タグ別の件数（今週／先週／累計）→ 「いじめの投稿が先週より増えている」が一目で分かる
- 学校コード別の件数（任意入力があった場合のみ）

## 3. 画面

### 子ども側（ログインなし）
| 画面 | 内容 |
|---|---|
| `/` | 「ここは、ひみつのポスト」説明 → 「かく」ボタン |
| `/write` | ①どんなこと？（家のこと／学校のこと／友だちのこと／自分のこと／してほしいこと）②だれに見てほしい？（先生／NPOの大人／どちらでも）③自由に書く ④学年帯（任意）⑤学校コード（任意・先生から教えてもらった番号） |
| `/sent` | 「とどきました」＋相談窓口＋「いますぐ危ないとき」 |
| `/about` | 保護者・先生向けの説明（何を集め、何を集めないか） |

文言はひらがな多め、漢字にはふりがなの代わりに簡単な言い換え。ボタンは大きく、1画面1アクション。

### 大人側（パスワード）
| 画面 | 内容 |
|---|---|
| `/adults/login` | 共通パスワード（環境変数 `ADULT_PASSWORD`） |
| `/adults` | 投稿一覧（新着順）。緊急は最上部固定・赤帯。タグ／緊急度／カテゴリ／対応状況で絞込。各投稿に「対応状況（未確認→確認済→対応中→対応済）」「内部メモ」 |
| `/adults/stats` | タグ別 今週/先週/累計、学校コード別 |
| `/adults/export` | CSV ダウンロード（本文・タグ・日時・状況・メモ） |

## 4. 技術
- Next.js 16 / Tailwind v4 / TypeScript（他プロジェクトと同構成）
- 保存: Upstash Redis（無料枠）。未設定時はプロセス内メモリで動作（デモ用・再起動で消える）
- 認証: `ADULT_PASSWORD` を HMAC したトークンを httpOnly Cookie に保存（パスワードそのものは Cookie に入れない）
- 連投防止: `sha256(IP + 日替わり塩)` をキーに 1日 20件まで。ハッシュは投稿に保存しない
- 迷惑投稿対策: ハニーポット項目、最小文字数、URL の多い投稿は「要確認」タグ
