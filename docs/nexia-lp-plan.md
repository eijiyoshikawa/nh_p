### メモから抽出したコアメッセージ
1. **子ども食堂に「価値」をつくる** — ただの子ども食堂は廃れる。
2. **既存を大切にしながら、増やす食堂を枚方のブランドにする**
3. **5つの視点で設計する新しい子ども食堂**
   - 子どもが行きたい／親が行かせたい／企業が参加したい／飲食店が始めたい／いろいろな人が関わりたい
4. **イメージは「学童保育 ＋ 子ども食堂」** — 親の負担・課題、子どもの興味と発達段階をクリア
5. **子どもプロジェクトの循環**: やりたい → 子ども会議 → プロジェクト → 達成
6. **将来構想**: 「株式会社ひらかたキッズ」的な仕組み（ものづくり・職業体験）。寄付＝投資、子どもを育てること＝株主になれるモデル（後々）

## 4. トーン＆デザイン方針

- **キーワード**: 未来・実験室（ラボ）・つながり（ネクシア）・枚方
- **印象**: 信頼感（行政向け）× ワクワク（子ども向け）を両立。既存 npo-lp（緑）とは明確に差別化
- **配色**:
  - ベース: オフホワイト `#FBFAF6` / インク `#1B1F2A`
  - ブランド: ラボブルー `#2457C5`（信頼・未来）
  - アクセント: サンライズイエロー `#FFB703`（子どものエネルギー）
  - サブ: コーラル `#FB6F5E`、ミント `#3ECFA0`（成長）
- **形**: 大きめの角丸、丸いドット／円形モチーフ（「ラボ」「つながり」）、マーカー風ハイライト
- **タイポ**: 見出し太字・大きめ。日本語システムフォント（Hiragino / Noto Sans JP）
- **モーション**: スクロールでふわっと表示、ヒーローの浮遊シェイプ。控えめ

## 5. 名前に込めた想い（案）

- **ミライ（未来）** — 子どもたちの10年後・20年後を見て動く
- **ラボ（Lab）** — 決まった正解がない。試して、学んで、つくり続ける実験室
- **ネクシア（Nexia）** — NEXUS（結び目・つながり）から。子ども・親・食堂・企業・行政をつなぐ場所

※ 案です。実際の由来と異なる場合は `src/lib/site.ts` の `nameOrigin` を修正。

## 6. 実装方針

- Next.js 16 App Router / Tailwind v4 / TypeScript（npo-lp と同構成）
- **全テキストは `src/lib/site.ts` に集約** → 非エンジニアでも文言修正可
- ニュースは `src/lib/news.ts` に配列で管理（後で MDX 化可能）
- お問い合わせ: `NEXT_PUBLIC_FORM_ENDPOINT`（Formspree 等）設定時はPOST、未設定時は mailto にフォールバック
- パスワードロック**なし**（一般公開）
- Vercel 新プロジェクト（Root Directory: `nexia-lp`）
