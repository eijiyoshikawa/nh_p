# 行政系資金調達 骨組み（②戦略）

**目的**: 他NPOが再現可能な「型」としての行政系資金調達フレームワーク
**対象**: 大阪府枚方市のNPO法人（子ども食堂支援）
**目標**: 行政系で1,000万円 / 倉庫設立総額1,500万円（残500万は①寄付+③CF）
**期限**: 2029年末

| 年度 | 主な採択 | 獲得額 | 累計 |

## 5. 再現可能な「型」にするためのポイント

### 他NPOに渡すべきテンプレート
1. **申請書テンプレート集** — WAM助成・府福祉基金・持続化補助金の記入例
2. **年間申請カレンダー** — 月次のToDoリスト化
3. **実績記録フォーマット** — 月次活動報告・受益者数・食材配送量の記録様式
4. **行政関係構築マニュアル** — 市の担当課との面談の進め方
5. **倉庫設立チェックリスト** — 物件選定→補助金申請→改修→運用の手順書
6. **資金調達ダッシュボード** — 申請状況・採択結果・獲得額の一覧管理表

### 「型」の核心
- **申請は「数」で確率を上げる** — 年間8〜10件を目安
- **小→中→大のステップ** — 実績なしにいきなりWAMは通らない
- **2本柱戦略** — WAM助成（福祉系最大）+ 空き家活用補助（自治体系最大）
- **1月が勝負月** — WAMと府福祉基金の締切が集中
